One funny line roasting my own AI agent: "My agent confidently called a tool that does not exist, then apologized in advance for the delay it was about to cause." Three real failure modes in one breath — the confident wrong answer, the phantom tool call, the apology loop — with the payoff landing on the last words: it apologizes in advance for a delay it is about to cause.

## Run it

```sh
node main.ts
```

`main.ts` writes the roast line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is a single line of 1–140 characters with no dash and no padding whitespace.
